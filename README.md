# 🌳 化学知识挑战树

**像打游戏一样学化学** —— 面向初中生的游戏化刷题网站。

闯关解锁知识点、升级段位、和同学 PK 排行榜。覆盖沪教版八年级化学。

## 🎮 特点

- **技能树闯关**：9 大章节、70+ 知识点，顺序解锁
- **综合大题**：真实考试场景，4-5 道子题连载
- **跳章测试**：答对 70% 一键跳过整章
- **排行榜**：全服 XP 排行，前三名领奖台，只显示昵称
- **错题本**：自动收录错题，原地重做
- **学习报告**：各章进度、薄弱知识点一目了然
- **答对彩带 + 叮咚音效**：正向反馈拉满
- **论坛**：同学之间讨论化学问题

## 🔑 学生怎么用

1. 老师给你一个邀请码
2. 打开网站，点「输入邀请码」→ 注册 → 填邀请码 + 学号 + 姓名 + 密码
3. 开始闯关！进度自动保存到云端
4. 下次用同样的邀请码 + 学号 + 密码登录
