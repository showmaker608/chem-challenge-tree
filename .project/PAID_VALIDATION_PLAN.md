# 置顶计划：化学挑战树首个付费闭环验证

> 建立日期：2026-08-29  
> 当前状态：方案定义中；尚未公开售卖；真实咨询、付费意向与到账均为 `尚未采集`。  
> 核心原则：先验证家长是否愿意为一个明确的教学结果付费，不先开发复杂支付系统。

## 当前三个卡点

1. **网站入口与信任**：已购域名，正在备案审核；在正式域名可用前，不用腾讯云测试域名公开放量。
2. **真实目标用户样本**：现有作品和互动练习不等于稳定流量，需要持续把“短视频问题”接到“对应练习和结果”。
3. **付费转化断点**：体验结束后目前没有明确商品、家长价值、咨询提交、报价与成交路径。

安全门槛和最小埋点是上线前置条件，不与以上三个增长卡点混为一谈；备案通过、公开引流前再做一次线上回归核验。

## 首个测试商品

### 开学化学诊断体验包（试售版）

面向：刚开学、家长不知道孩子化学具体卡在哪里的上海初中学生。

交付内容：

1. 约 15 分钟的基础诊断；
2. 7 天内 3 次针对性短练习，每次约 10 分钟；
3. 一份可读的错因与薄弱点报告；
4. 一次约 10 分钟的家长结果解读与下一步建议。

交付边界：

- 不承诺 7 天学完整册，也不承诺具体提分；
- 报告称“初步薄弱点”，不夸大为完整能力诊断；
- 网站承担练习和记录，老师的判断与解读才是首个付费商品的核心价值；
- 第一阶段人工交付，不开发会员、购物车或自动支付。

### 测试价格

- 第一批限 3 人：**49 元/人**，目标是验证第一次真实付款；
- 若至少 1 人真实付款、完成交付，且单人额外人工时间可控，再用第二批 3 人测试 **99 元/人**；
- 以上仅是验证价，不代表长期定价。

## 最小转化链路

`短视频提出一个问题` → `免注册完成对应练习` → `看到初步结果` → `家长看到诊断体验包` → `提交咨询` → `老师确认是否适合并明确报价` → `愿意进入付款步骤` → `真实到账`

必须分别记录：

| 阶段 | 判定标准 |
|---|---|
| 到达 | 打开对应体验页 |
| 开始体验 | 触发第一道题或第一步操作 |
| 完成 | 到达结果页 |
| 咨询点击 | 只点击咨询入口，不算咨询提交 |
| 主动咨询 | 提交可联系信息或主动发来有效咨询 |
| 已报价 | 家长看过明确价格、交付和时间安排 |
| 付费意向 | 家长明确愿意进入付款步骤 |
| 真实付费 | 款项实际到账 |

没有采集到的阶段写 `尚未采集`，不能用网站请求量、账号数、点赞或播放量替代。

## 备案等待期的执行顺序

- [ ] 找 3 名符合目标的学生/家长，不公开群发；

### 第 3 阶段：备案通过后公开闭环

- [ ] 绑定正式域名和 HTTPS；
- [ ] 复核线上安全门槛和最小埋点；
- [ ] 手机实测“视频入口 → 免注册练习 → 结果 → 咨询提交”；
- [ ] 再发布已储备的视频并使用正式入口承接。

## 第一轮决策门槛

首轮先看绝对人数，不急着包装成转化率：

- 至少 10 个符合目标的家庭看过明确方案；
- 至少 3 个家庭产生有效咨询；
- 至少 3 个家庭收到明确报价；
- 至少 1 笔真实付款；
- 完成交付后记录学生是否完成 3 次练习、家长是否认为报告有用，以及是否愿意继续或推荐。

若没有付款，按断点调整：

- 没人完成体验：先改入口和练习节奏；
- 完成但没人咨询：先改结果页价值表达与商品匹配；
- 咨询但报价后退出：检查价格、信任、交付内容和时间成本；
- 有付款但无人完成：先改交付和留存，不扩大流量。
