# 学习模式项目优化清单

建立日期：2026-09-05。用途：独立跟踪化学挑战树学习模式的教学与使用优化。

## 范围与证据

- 覆盖当前 `defaultCourse.chapters` 八、九年级主线 85 个节点，包括互动实验和非互动学习项目；不包括账号、排行榜、论坛、支付及独立复习题库。
- 本轮已读取课程装配、节点数据、学习目标分流、互动注册和学习弹窗关键分支；已运行 `bun run audit:learning`，八年级 45、九年级 40 个节点通过。
- 结构检查通过只代表基础字段和迁移题数量符合脚本要求。未逐项做浏览器、投影、手机或学生实测，未核实线上版本；下面待验项目不是已确认故障。
- 课程安排以老师讲义为准。下周领航、腾飞均包含蜡烛内容；其余项目按实际授课先后推进，不擅自认定某内容超纲。
- 优先级：P1＝下周使用前或直接影响学习目标；P2＝随对应授课推进；P3＝不急于开发，先确认需要。

## 更新规则

- 状态依次记录：待核验 → 已确认问题 → 已修改 → 本地验证 → 线上验证 → 课堂/课后验证。勾选前写明完成了哪层验证。
- 每次优先处理影响下节课和独立复习的 1—2 项，不把全表同时变成开发任务。
- 下方目录用于防遗漏；“待逐项核验”不等于需要重做。新增/移除节点后重新对照课程装配更新。
