# 化学对决：自由组牌 v1

2026-09-11，本地实现，未部署。首页“开始对决”直接使用预设或已保存牌组；“我的牌组”独立编辑并保存。初次进入自动开始入门对局，原有练习收纳在帮助中。

## 构筑与对局

- 全部 17 种卡牌开放，不设付费或解锁门槛。
- 一副 16 张；至少 10 张物质，最多 1 张英雄、4 张战术。
- 同名物质最多 2 张，其余同名最多 1 张。重复物质只有基础分，不产生同名叠加奖励。
- 起手随机 10 张，可换 2 张，剩余 6 张为备用。换入的牌不能再次换走；局间不自动补牌。
- 三套预设：反应接力、守证反击、灵活调度；可自行加减卡牌。
- 保存当前浏览器的一副牌组，损坏数据退回预设。不修改学生账号、学习进度或云端同步。当前不支持多副命名收藏或跨设备同步。
- 电脑从不同构成的预设牌组取牌。开战前可看完整牌组构成，不公开手牌与抽牌顺序。双方共享可选卡池，不保证每张牌身份完全不重合。

## 新牌

| 卡牌 | 规则 |
| --- | --- |
| 实验导师 | 英雄 5 分，在场后首次完成新检验接力，自身再 +2，每局一次 |
| 见证者 | 英雄 5 分，在场时挡下己方首次受到的成果质疑，每局一次；不追溯解除旧质疑 |
| 访问学者 | 间谍，给对手 4 分，自己从备用抽最多 2 张 |
| 精密测量 | 己方未反应、未获奖励的物质 +3，本局有效 |
| 成果质疑 | 暂扣对方一张物质的组合奖励，不减基础分、不否定反应事实 |
| 实验复核 | 恢复己方一张物质被质疑的组合奖励 |
| 紧急调度 | 收回己方未反应、未获奖励物质，同时换上一张手牌物质；已参与催化的牌不能收回 |

所有战术需要合法目标才可出牌。结算后弃置；修正值与质疑随换局清空。物质反应记录保持原有规则：每种链每侧每局一次，检验材料可提前放置。
